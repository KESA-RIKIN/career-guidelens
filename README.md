# career-guidelens
Career guidance web app built during Ideathon 2025
Career Guidelens

**Career Guidelens** is an AI-based career guidance platform developed during **Ideathon 2025**.  
It helps students identify suitable career paths based on their interests, skills, and goals.

---

## 💡 Features
- Personalized career recommendations
- Interactive quizzes to understand interests
- Dashboard to track progress and goals
- Simple and responsive UI

---

## 🧠 Tech Stack
- HTML, CSS, JavaScript  
- Firebase (Authentication + Database)
- OpenAI API / Chatbot for guidance (optional)
- Responsive Frontend Design
